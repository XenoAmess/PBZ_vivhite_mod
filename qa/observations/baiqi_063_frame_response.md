# 白绮 063 镜框受光

062 的镜框在正面和侧光下容易形成一条抢眼的白色弧线。保持形状、原金色贴图和 0.62 金属度，比较粗糙度 0.36、0.46 和 0.56。另测降低金属度，正面主光下变亮的面积反而增加。最终选用 0.46，保留逆光下的金色轮廓。

三种灯位用隐藏镜框帧作对照。眼区内比隐藏帧亮至少 25 个显示亮度单位的像素，在主光下由 486 降到 356，侧光由 91 降到 29，轮廓光由 422 降到 388。部分单点峰值仍会升高，这次改善主要体现在高亮覆盖面积。最终文件也用同一相机复渲染，眼图、脸颈肤色和发丝未改。

93 张游戏输入仅镜框的混合贴图变化。原生粗糙度编码由原 0.34 更新到 0.46，金属度、眼部四种状态、脸部局部法线及色图保持 062。两套 UE 网格各 348 骨，原表情材质切换与外套区段读回通过。两套形态各验证 33 组动作、197 个姿态，所有变形及服装接触数据与 062 一致。

复现使用 `scripts/apply_baiqi_frame_roughness.py`，游戏贴图烘焙添加 `--surface-finish --frame-roughness .46`。当前发布为离线候选存档，实际游戏光照留在发行前验证阶段。

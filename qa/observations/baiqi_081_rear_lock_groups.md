# 白绮 081 后发束分组

后脑 23 片发束的宽度和收尖规律接近，后视轮廓像一排等距尖齿。试验在保持头顶和发根位置的前提下，让下段按两到三束分组。第一版向组中心收拢后，后颈上方出现新的露缝。增加相邻发束的覆盖宽度，把收拢起点移到更靠近发梢的位置，再保留少量长度差。

选定版调整 19 片发束的下段，共 4,275 个顶点，最大位移 3.94 毫米。正面、侧面、后方与斜后方的对照中，发根和头顶轮廓保留。用固定分区和暖色阈值量后颈露肤，上带从第一轮强档的 1,514、1,668 个像素降回 0，和 080 相同。紧邻下带的暖色像素在后视由 881 减至 580，在斜后视由 726 减至 466。范围只用于这些同机位图的对照。

两种形态各复验 33 组动作、197 个姿态。后发束与头部逐帧相交数均为 0，前发与脸、镜框也为 0。前后发束之间的每帧交叉数由 3,911 降至 3,886。其余变形及服装接触指标逐帧一致，各保留 20 项原 CC0 记录，新增标记为 0。抽看转头、抬低头和双刃攻击近景。

两套 FBX 只有后发材质区段变动，各 7,600 个三角面坐标变化，区段全部 19,408 个三角面的 UV 一致。99 张原生纹理一致。UE 5.7.4 读回两套 348 骨骼、现有网格区段及四种眼部状态。原脸、原嘴、CC0 身体、骨架与服装保留。此版为离线候选。

用 `scripts/group_baiqi_rear_hair.py` 处理 080 的两套工程，动作套组加 `--rear-lock-contacts`，即可复验后发与头部的接触。存档附两套完整工程、烘焙输入、分组试验及动作报告。

# 全身统一检查与修复顺序

当前候选的全身形体不合格。此次统一检查替代只盯肩颈的局部判断，不能用原生骨骼长度或数值零超限推导模型自然。

## 固定证据

`shape_audit_v1.json` v1.1.0：全身八视角，十三个局部各六视角，灰模/贴图共 172 张。局部包含头、肩颈、躯干、双上臂、双肘、双手、骨盆、腿、膝、脚。v1.0.0 的首批 88 张诊断保留；它缺少部分背面与另一侧局部，不能充当完整验收。

基线 `repair_015_v11` 使用 `build/qa_pre_inputs_015/Delta_adult.blend`。输入、配置、执行代码的 SHA256 在 `shape_manifest.json`。本次只是失败基线，不是新交付模型。原始角色以 Delta.zip 的 Live2D 渲染为准，full.jpg 不参与。

## 已观察到的问题

| 部位 | 当前结论与证据 |
| --- | --- |
| 头 | 颅顶过平、后脑近方盒，侧脸和下颌存在尖角及不自然的台阶。灰模可见，属于几何问题。 |
| 肩颈 | 颈部呈直柱，肩顶凸起，颈肩过渡和角色原有衣领结构不自然。 |
| 躯干 | 胸廓像硬板，胸背、腰部缺少连续的体积变化；上半身贴图与下摆有明显横向分界。 |
| 双上臂 | 袖子呈均匀管状，肩头和肘部轮廓僵硬。需要同时核对可见肢体长度、袖口位置和骨骼关节位置。 |
| 双肘 | 中立轮廓有折线；还须单独看弯曲采样，不能仅根据中立图判定蒙皮。 |
| 双手腕与手 | 腕部接缝，硬块状手掌，独立圆柱状手指，拇指根部缺少连续体积，还有悬空碎片。 |
| 骨盆与服装 | 裙摆局部堆叠、褶边粗糙；衣服遮住了骨盆，必须补独立基础形体检查，不能按遮挡后的画面宣称骨盆正确。 |
| 腿与膝 | 大腿、小腿局部块状转折，膝部轮廓生硬。Delta 的长腿风格应保留，长度和围度需要对照角色参考核对。 |
| 脚与鞋 | 踝口接合、鞋面和鞋底有不自然的折叠及拉花；脚掌和鞋跟还须在统一地平面检查接触。 |

## 修复顺序与放行

1. 固定角色整体比例与关节标志点，检查完整灰模基础形体：颅顶、面颌、胸廓、骨盆以及四肢。明确区分裸露皮肤和服装体积，不能将同一表面强行充当两者。
2. 修复连续拓扑和局部体积：肩、肘、腕、手指根、膝、踝；移除悬空碎片和内部重复表面。
3. 整理外套、衣领、袖口、裙摆、鞋与头发，核对正面设计和推断背面，修复 UV 与材质边界。
4. 保留成年魂原生 264 骨与参考变换，重新检查蒙皮；模型问题与权重问题分别记录。
5. 完整静态形体检查通过后，用固定 ROM v1.0.0 的 30 组动作、182 个姿态重新渲染 1,092 张图，再检查真实游戏动画、烘焙读回和实机。

`qa.review_gate` 要求所有十三个形体部位通过、对应输入哈希一致、无未关闭问题，同时要求 ROM 覆盖和逐项复查通过。缺失、待查和失败均不得进入实机。

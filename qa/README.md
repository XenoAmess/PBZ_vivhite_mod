# Humanoid ROM acceptance suite

本目录维护人物模型的离线验收规范、关节映射和渲染配置。当前状态：**Delta 的肩颈测试失败，禁止进入实机验收**。

本项目规范参考公开制作流程，属于项目验收标准，不宣称是行业统一认证，也不复制 MetaHuman 的专用姿态或模型数据。

流程：固定配置与输入哈希 → 中立形体检查 → 单关节 ROM → 多关节组合 → 同参数多视角灰模/贴图 → 数值定位和逐图检查 → 修复 → 全量回归。已发现的问题必须有关闭证据；仅数值通过不得放行实机。

公开仓库维护代码、配置、文档、结构化记录、用户提供的模型、烘焙包与完整 Blender 工程。游戏文件选择性保存复现所需的骨架、参考网格与动作。本机密钥、登录凭据和其他机密信息不上传。

资料依据见 [sources.json](sources.json)。实现与动作覆盖正在扩充；禁止把未实现的动作或未检查的图片标为通过。

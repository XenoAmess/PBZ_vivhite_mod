# 白绮：女性基模上的角色迁移

目标是把 `Delta.zip` 中白绮的外观、服装及全部附加组件迁移到结构完整的女性基模，最终替换成年魂。`full.jpg` 是另一位角色，不参与本工程。玉儿与沐小葵用于女性结构对照，不代替白绮的角色设计。

**当前是未通过验收的制作工程，不是可安装成品。** 已为 98 个 Part 及一片无父 Part 的外套底片建立三维目标；映射不表示形体、动作或角色还原已经通过。

## 基础与原始资料

- 人体采用旧版 VRoid Project `Base_Female.vrm` 的皮肤网格，包括头部、躯干、四肢及手指。具体资产的嵌入元数据标注 CC0，保留原始 ZIP，不能把该许可推广到当前 VRoid 的所有资源。[旧版许可说明](https://vroid.pixiv.help/hc/en-us/articles/4402614652569)。
- 只使用成年魂的原生 264 骨参考。女性网格映射到这些骨骼，未修改父子关系和参考矩阵。衬衣、裙子和鞋的部分拓扑来自同一 CC0 资源，外观使用白绮原图并重新制作配件几何。
- 使用官方 Cubism Core 读取用户 `.moc3` 的 98 个 Part、290 个 drawable、167 个参数、原始 UV、遮罩和全局绘制顺序。[Core 文档](https://docs.live2d.com/en/cubism-sdk-manual/cubism-core/)。官方 DLL 仅在本机工具目录，不随仓库分发。
- 25 个原始表情/切换预设已保存并制作 Blender 预览。机械装置与屏幕同时开启的组合直接用 Core 求值，不把两份差异数据简单叠加。

## 各种组件的迁移方式

| 原始内容 | 三维表示 |
| --- | --- |
| 脸、眉眼、嘴、表情图形 | 烘焙到女性头部及眼部表面，保留源状态图集 |
| 前发与后发 | 源轮廓与纹理决定刘海，侧后体积重建为发束；未绘制的背面须单独审查 |
| 眼镜、镜腿、黑金头饰 | 贴合头部的独立几何，保留源颜色与纹样 |
| 衬衣、领结、束腰、外套、百褶裙 | 贴合女性人体的服装表面及厚度，保留金边、系带、纹样和裙摆设计 |
| 袖子、袖口、腕带、蓝色臂结 | 使用原生手臂的蒙皮与空间位置重建，不能把源二维坐标直接用作三维位置 |
| 长袜与鞋 | 长袜外观跟随女性腿部，鞋使用三维足部形体并校准原生地面参考 |
| 隐藏马尾、机械装置、屏幕、手部光环、星图 | 分开保存与切换；机壳有厚度，光翼、屏幕、光环和星图按全息效果处理 |
| 层级组与蒙皮锚点 | 映射到子组件或相应三维部件，不虚构可见实体 |

有 5 片属于 `Fhair` 的网格通过 `Facecolor` 遮罩绘制脸部投影。它们属于脸部外观，不能建成悬浮在眼睛前面的头发。无父 Part 的 `ArtMesh215` 是外套底片，也纳入清单。

`components.json` 保存逐项目标与状态，`source_contract.json` 固定原始覆盖范围。98 个 Part 包含容器、表情与人体绘图层，不等于 98 件独立服饰。原生手部可承载替代手势，但仍需专门制作和对照验收。

## 当前发现与失败记录

- 逐层投影和体素合并的头发均有失败样件，不能当成最终头型。
- `baiqi_components_007` 的动作图发现人体未随骨骼运动、衣物却在运动。原因是曲线转网格误作用于仍被选中的人体，移除了蒙皮修改器。该轮动作验收作废，图和错误工程保留。
- 已改为只从眼镜曲线求值生成网格，恢复人体蒙皮，并增加全模型绑定检查、原生参考矩阵检查和实际运动响应探针。骨骼数为 264 或伸长数值为零，都不足以证明正确绑定。
- 后续继续检查肩部衣片接合、衣领与发梢、侧后外观、替代手势，以及抬臂、抬腿和下蹲时的服装穿插。
- Blender 状态控制器尚未接入游戏。新材质、透明/全息效果和角色包尚未完成 UE 烘焙及读回验收。

## 复现与长期验收

安装 `requirements.txt` 后，可用 `scripts/prepare_baiqi_reproduction.py` 恢复原始素材，`repro/` 保存完整制作工程与检验输入。直接查看上传的 Blender 工程不需要安装 Cubism SDK。

先检查 172 张固定全身/局部图，再检查同一模型的 1,092 张 ROM 图，逐项记录问题。灰模保留真实 alpha 轮廓；渲染覆盖所有可见部件，数值定位明确标注采用的人体网格。

进入实机之前，必须同时通过形体、全部动作、白绮组件与状态、原生绑定及烘焙读回检查。任一项待审或失败均不允许进入实机。

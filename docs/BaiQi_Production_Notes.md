# 白绮制作与验收经验

这份记录梳理 `Delta.zip` 从 Live2D 原画到成年魂外观的制作过程。当前复用基线是 103。使用另一份人物全身参考图 `full.jpg` 时，应另建角色工程。安装和复现入口见 [白绮交接手册](BaiQi_Handover.md)。

## 形体与角色识别

- 用原画拆出的脸、发片、镜框、衣装和装饰建立可独立修改的几何和 UV。正面的纹理能够用原画对齐，侧面与背面的体积要从多视角检查。早期 Hunyuan3D-2.1 试验用于探索三维形体。103 的局部修复使用 Blender 网格、投影和材质编辑，可以直接从已归档的工程迭代。 [原始组件迁移记录](../characters/baiqi/MIGRATION.md)
- 骨架与身体使用锁定的 CC0 基模，头脸用用户确认的作者版本。衣装和补颈在身体外拟合，领口下的内搭要贴身，外套需要自己的余量。面部与上臂使用同一基础肤色，面颊原绘明暗留在各自贴图。出现拉伸、折角或碰撞时，先把相同姿态放到原 CC0 对照上复现。原基模可复现的缺陷单独记录。 [颈肩与肤色对照](../qa/observations/baiqi_092_neck_shoulder_review.md)
- 用户要求省去替代嘴型和 `ArtMesh53` 的全身乘色。发、眼、金边等组件用原模型身份与用户清单核对。双形态维持同一角色的内搭，脱外套参考清单第 44 项的整体造型。原 Part 名、ArtMesh ID 和评审清单编号分别核对，避免同名误用。 [原料目录](../repro/README.md)

## 先找异常属于哪一层

| 症状 | 有效做法 | 对照 |
| --- | --- | --- |
| 仰视时出现两道嘴线 | 底色确认原 `Mouth2`，灰模定位旧三维开口。沿原画闭口唇线重建局部曲面，再比较三档唇部起伏。用正、斜、侧和约 20° 至 42° 仰视核对闭口神态。 | [099 双线修正](../qa/observations/baiqi_099_closed_mouth.md)、[100 唇部体积](../qa/observations/baiqi_100_lip_volume.md) |
| 脸颈扁平，或出现一块过暗的鼻翼、下颌 | 用同机位底色、灰模和受光图分离旧描线、几何和法线。保留面部基准色，针对真实来源调原图局部、补颈或切线空间法线。副作用用反侧灯验证。 | [鼻梁法线](../qa/observations/baiqi_096_nose_ridge.md)、[下颌原画投影](../qa/observations/baiqi_097_underjaw_tint.md)、[补颈受光](../qa/observations/baiqi_084_neck_normals.md) |
| 前发侧面有连续尖齿，镜框反光成串断点 | 对照 alpha 裁切结果和原图。相邻三角面的长短边错开会打断平滑法线。镜框加厚时，这些接边还会生成 1,524 个额外侧壁面。前发和圆镜框都用共享细分中点处理，之后只给侧下发梢局部加密。 | [前发裁切](../qa/observations/baiqi_101_fringe_cutout.md)、[镜框裁切](../qa/observations/baiqi_102_frame_cutout.md)、[发梢采样](../qa/observations/baiqi_103_fringe_tips.md) |
| 侧面下颌附近像多了一块皮肤 | 单独显示 CC0 身体、白绮头和补颈，再拉远看参考姿态。纯侧面把远侧的手投到了颈部附近，动作套组中要用放臂姿态复看。 | [皮肤分区对照](../qa/observations/baiqi_100_profile_projection.md) |

极端灯光也可以用来定位问题。头顶侧后光的窄暗边已经对比了几何降高、深度调整和三档局部法线。优先保留 103 原画发峰的形状。发饰裁切也做了实验，成像差异只有零星像素。保留这些负向结果可以避免接手人重复试验。 [头顶复查](../qa/observations/baiqi_103_crown_profile_review.md) [发饰裁切试验](../qa/observations/baiqi_102_headdress_cutout_review.md)

## 一轮调优怎么验收

1. 固定候选提交、两个工程哈希、动作套组、镜头和灯光。建立旧版对照后，每轮只改一个可定位因素。
2. 同画面切换贴图、灰模、材质分区、投影开关。分别观察正面和换灯后画面，补左右斜视及问题出现的原角度。以问题区域的测量辅助判断，以并排图确认轮廓、神态和相邻区域。
3. 用锁定的 CC0 身体和相同动作供体检查形体、衣装和头颈。常规回归每形态 33 组、197 姿态，包含 37 个组合颈姿以及成年魂待机、跑步、双刀出招。优先复看动作极值和最容易露出接缝的机位。 [103 双形态复查](../qa/observations/baiqi_103_integrated_review.md)
4. UE 读回两套 348 骨骼网格、材质区段和四种眼部切换。五个常规机位、两个形态与五种眼部状态共 50 图。嘴部八机位、两个形态及两套渲染共 32 图。Blender 新法线导出后也要检查 UE 结果，发底曾只有烘入切线贴图才在引擎中出现改动。 [发底法线对照](../qa/observations/baiqi_095_crown_relief.md)
5. 合格候选单独提交，并归档两套完整工程、FBX、原生烘焙和验收证据。归档包含可核对的哈希。正式游戏发行还要单独验证运行时装配、姿势、布料、换装状态和音频。 [版本索引](../repro/baiqi_model_versions.md) [长期验收规则](../qa/MAINTENANCE.md)
